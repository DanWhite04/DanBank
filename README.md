# DanBank
## Description
A CLI banking app that allows the user to input a desired account name alongside the starting amount in the accounts with 
a pin that allows the user to log in the account. This account that is created is stored and can be logged into after stopping the run session.

## Features
- Create account and stores account information using File I/O
- Allows for deposit, withdrawal from and into the account
- Pin authentication once account is created only allowing correct PIN into the account, if incorrect user will be prompted with a retry
- Transactions history of all transactions that are made within the account meaning both withdrawal and deposits
- Employs OOP practices

## How to run
- Run javac Main.java then java Main into the terminal

## Technologies 
- Java 25
